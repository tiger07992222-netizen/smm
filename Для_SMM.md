# Инструкция для SMM: бот Scores24

Кому: человек, который ведёт посты в Telegram через админ-бота и добавляет языковые каналы.  
Сервер и Docker обычно настраивает разработчик — здесь про **бота**.

Админ-бот: **@scores24_smm_bot** (напишите в личку, не в канал).

---

## 1. Получить доступ (первый шаг)

Без доступа бот отвечает: «Напишите пароль» / игнорирует команды.

**Вариант А — пароль (проще)**  
1. Админ даёт вам пароль из настройки `SMM_PASSWORD` (не публикуйте его).  
2. Откройте бота → Start → отправьте пароль **одним сообщением**.  
3. Ответ: «Доступ открыт» и появится меню внизу.

**Вариант Б — ваш Telegram id**  
Админ добавляет ваш числовой id в `SMM_USER_IDS` на сервере и перезапускает бота. Пароль не нужен.

Узнать свой id: напишите любому боту вроде @userinfobot.

После доступа нажмите **Справка** в меню или команду `/help`.

---

## 2. Справка внутри бота

В любой момент:

- кнопка **Справка**, или  
- команда `/help`

Там же кратко: меню, слоты, как добавить канал.

---

## 3. Меню

| Кнопка / команда | Зачем |
|---|---|
| **Статус** `/status` | Очередь постов на сегодня (если каналов несколько — сначала выбор канала) |
| **Посты** `/posts` | Список черновиков дня, открыть любой |
| **Собрать** `/generate` | Пересобрать день для выбранного канала (fetch + тексты) |
| **Каналы** `/channels` | Список каналов, добавить язык, выбрать активный, привязать TG |
| **Ссылки** `/links` | Подписи и URL под постами (фрибет / abroad) |
| **Справка** `/help` | Эта памятка в чате |

Обычный день идёт **сам** утром (~09:30 МСК): данные → посты → публикация по слотам.  
В личку бот пишет в основном, если валидатор зарубил пост или слот не ушёл.

Слоты по умолчанию (МСК, могут отличаться у EN-канала): топ матчи / экспресс / ставка / тренд — см. статус дня.

---

## 4. Добавить другой язык / канал

1. **Каналы** → **➕ Добавить канал (язык)**.  
2. Пришлите **slug** латиницей без пробелов, например `scores24-en`.  
   Это внутренний id в системе, не @username канала.  
3. Название (title), например `Scores24 EN`.  
4. Locale (`en`, `pt`, `es`…) — язык API и текстов.  
5. Timezone — слоты и offset для API.  
6. Бот сделает канал **активным**.

**Привязать Telegram-канал**

1. Добавьте **того же** бота админом в новый TG-канал (постить + править сообщения).  
2. В админ-боте выберите этот канал в **Каналы**.  
3. Перешлите в админ-бота **любой пост** из нового канала.  
4. Бот сохранит chat id.  
5. **Собрать** — проверить посты; публикация пойдёт в привязанный канал.

Подписи ссылок («For Russia» и т.п.) подставляются по locale; URL правятся в **Ссылки**.

---

## 5. Если валидатор не пропустил пост

Придёт сообщение с ошибками и кнопками:

- **Посмотреть пост** / **Править текст** — правите текст следующим сообщением  
- **Другой текст** — другая обёртка, купон тот же  
- **Другой пик** — следующий прогноз этой рубрики  
- **Не публиковать** — снять рубрику на сегодня  
- **В канал сейчас** — не ждать слота  

После матча бот обычно сам ставит ✅/❌; если завис — кнопки «зашло» / «не зашло».

---

## 6. Что обычно не нужно трогать

- `.env`, Docker, сервер — у разработчика / DevOps  
- Секреты (`TELEGRAM_BOT_TOKEN`, `SCORES24_INTERNAL_REQUEST`, ключ LLM) никому не пересылать  

Код и деплой: репозиторий GitHub (private), доступ по приглашению Collaborators.

---

## 7. Чеклист новому человеку

1. Получить пароль или попасть в `SMM_USER_IDS`  
2. Написать @scores24_smm_bot → пароль → меню  
3. **Справка**  
4. **Статус** по нужному каналу  
5. При новом языке — **Каналы** → добавить → привязать пересылкой → **Собрать**
