# Четыре рубрики канала Scores24

Канал `scores24` публикует **4 поста в день**. Конфиг: [`config/channels/scores24.yaml`](config/channels/scores24.yaml).

| Время (МСК) | ID в коде   | Название в боте | Что это |
|-------------|-------------|-----------------|---------|
| **10:00**   | `top_matches` | матчи дня     | Дайджест главных футбольных матчей |
| **11:00**   | `express`     | экспресс      | Экспресс из 2+ ног (можно микс спортов) |
| **14:00**   | `bet`         | ставка дня    | Одна нога — «прогноз дня» |
| **17:00**   | `trend`       | тренд         | Одна нога — статистический тренд |

---

## Как устроен день (расписание)

Все времена — **Europe/Moscow**.

```
09:30  Утренняя генерация (cron + команда /generate)
       ├─ GET Scores24 API → пики в data/picks/
       ├─ top_matches: дополнительно GET /rapi/predictions/sports
       ├─ Селектор выбирает по 1 пику на рубрику
       ├─ Код + LLM собирают текст
       ├─ Pillow рисует картинку (кроме top_matches — только текст)
       └─ Валидатор → статус approved или needs_human

10:00  Публикация top_matches (если approved)
11:00  Публикация express
14:00  Публикация bet
17:00  Публикация trend

каждую минуту   publish_tick — догоняет approved-посты, если слот прошёл
каждые 10 мин   settle — после матчей дописывает ✅/❌ в опубликованные посты
```

**Важно:** в канал уходит только пост со статусом `approved`. Если валидатор не пропустил (`needs_human`) — в слот пост **не публикуется**, SMM получает алерт в админ-боте.

Перед публикацией проверяется **kickoff gate**: матч не должен начаться раньше чем за `publish_buffer_minutes` (5 мин) до слота.

Ручной запуск: `/generate` в админ-боте `@scores24_smm_bot` (пересобрать черновики), кнопка «Опубликовать сейчас» — вне слота.

---

## Общая схема: кто что делает

```
Scores24 API          Код (smm/)                 LLM (если есть ключ)
     │                      │                              │
     ├─ predictions/top ───►│ parse → Pick               │
     ├─ predictions/sports ►│ top_matches кандидаты      │
     │                      │                            │
     │                      ├─ флаги, матчи, линии, кэфы │
     │                      ├─ статистика (📊 / 💡)    ├─ intro / closing / promo_text
     │                      ├─ 3 ссылки из config      │   (или весь пост для top_matches)
     │                      └─ locked_facts            │
     │                              │                   │
     └──────────────────────────────┴──► Валидатор ──────┘
```

| Часть поста | Кто пишет |
|-------------|-----------|
| Команды, флаги, линия, кэф | **Код** (`copywriter.py`, `top_matches.py`) |
| Статистика под прогнозом | **Код** из `stat_text` API (или нарратив из голосов) |
| Intro / closing | **LLM** или шаблон без ключа |
| Текст 3-й ссылки (фрибет) | **LLM** → подставляется в promo-ссылку |
| Ссылки 1–2 (экспрессы / канал) | **config/default.yaml** → `links` |

## 1. Матчи дня (`top_matches`)

### Описание
Утренний **футбольный дайджест**: до 10 матчей, сгруппированных по лигам. Только футбол. Без картинки-карточки — длинный текстовый пост.

### Откуда данные
- `GET /rapi/predictions/sports` — кандидаты на календарный день
- Ранжирование лиг/клубов: `config/rankings/football.yaml` + правила в `smm/top_matches.py`
- Пик сохраняется как `Pick` с `type: top_matches`

### Кто пишет текст
**Отдельный LLM-вызов** в `llm_rank_and_compose_top_matches()` — не общий copywriter экспресса/тренда.

- System: skill [`smm/skills/top_matches.md`](smm/skills/top_matches.md) (подмешивается в bootstrap как `top_matches`)
- User: JSON кандидатов + лимит матчей
- Ответ LLM: `selected_ids` + `post_text` (весь пост или intro + тело из кода)

Fallback без LLM: шаблонный intro + `format_top_matches_body()`.

### Пример вывода

```
ВСЕ ГЛАВНЫЕ МАТЧИ ПЯТНИЦЫ ПРЕДСТАВЛЕНЫ НИЖЕ 🤩

🇪🇸 Ла Лига

Барселона - Атлетик
💡 Ставка: Обе забьют (Да)
📈 Кэф: 1.85

🇩🇪 Бундеслига

Бавария - Штутгарт
💡 Ставка: Ф1 (-1.5)
📈 Кэф: 1.67

👉 Больше футбольных прогнозов здесь
👉 Наш основной канал
🔥 Фрибет от нашего партнёра ждёт тебя по ссылке ниже.
```

### `locked_facts`
Для каждой ноги: `home`, `away`, `line`, `odds`, `tournament`. Без intro и без stat_text серий.

### Промпты

| Роль | Шаблоны |
|------|---------|
| Ранжирование + пост | `smm/skills/top_matches.md` |
| Валидатор (LLM) | `smm/skills/validator_top_matches.md` + `validator.md` + `scores24.md` + `meta.md` |
| Copywriter express/trend | **не используется** |

### Валидатор (дополнительно к общим правилам)
- Только football, 1–10 матчей, без дублей `match_id`
- Нет английских кодов рынков (`both to score`, `handicap1`, …)
- Кэф каждой ноги есть в тексте
- LLM проверяет смысл ранжирования (топ-клубы не ниже середняков без причины)

## 2. Экспресс дня (`express`)

### Описание
**2+ ноги** в одном купоне, общий кэф. Спорты могут смешиваться (футбол + теннис). Пост с **картинкой** (Pillow).

### Откуда данные
- `GET /rapi/localized/express` — первый купон с эндпоинта (бэкенд уже отсортировал)
- Селектор: без коридора кэфа, только kickoff / слот

### Кто пишет текст
- **Код:** блоки по спортам, флаги, `🔝 линия — кэф`, статистика в **blockquote** (📊 курсивом в Telegram)
- **LLM:** только `intro` + `promo_text`; `closing` = пусто

### Пример вывода

```
Экспресс на 20 августа с кэфом 3.24 уже готов 😎

⚽️ Футбол:

🇳🇱 ПСВ - Фортуна Ситтард 🇳🇱
🔝 Ф2 (+2.5) — кэф 1.76

📊 Фортуна Ситтард побеждает с форой +2.5 на выезде в 10 из 11 последних матчей (Эредивизи).

🎾 Теннис:

🇨🇿 Иржи Легечка - Рафаэль Ходар 🇪🇸
🔝 П2 — кэф 1.84

📊 Рафаэль Ходар побеждает в 6 из 7 последних встреч.

👉 Больше экспрессов ждет тебя здесь
👉 Наш основной канал
🔥 Фрибет от нашего партнёра ждёт тебя по ссылке ниже.
```

Если API отдал только «согласны X%, голосов Y» — код превращает это в связное предложение (без выдуманных «8 из 9»).

### `locked_facts`
- Общий кэф экспресса
- На каждую ногу: `home`, `away`, `line`, **нарратив stat_text**, `odds` ноги

### Промпты

| Роль | Шаблоны |
|------|---------|
| System copywriter | `copywriter_base.md` + `copywriter_express.md` + `scores24.md` + `meta.md` |
| User | `user_express.md` |
| Repair | `repair.md` + base + express + … |
| Validator | `validator.md` + `scores24.md` + `meta.md` |

Сборка: `build_system_prompt("copywriter", "scores24", post_type="express")`.

### Валидатор (специфика)
- Экспресс должен иметь **≥ 2 ноги**
- Все строки из `locked_facts` — подстрокой в `text` / `text_html`

## 3. Ставка дня (`bet`)

### Описание
**Одна нога** — сильный прогноз на матч (блок `prediction` / `bet` в API). С картинкой.

### Откуда данные
- `GET /rapi/localized/express?section=betoftheday` — первый прогноз с эндпоинта
- Селектор: без коридора кэфа, только kickoff / слот

### Кто пишет текст
- **Код:** спорт, команды, `🔝 линия — кэф`, статистика в формате **💡 … : ✅/🔻 …** (`format_stat`, маркер 🔻)
- **LLM:** `intro`, `closing`, `promo_text`

Шаблон без LLM пишет intro со словами **«Ставка дня»**.

### Пример вывода

```
Ставка дня в теннисе: разбираем тур 🎾 🔝

🎾 Теннис:

🇺🇸 Джессика Пегула - Диана Шнайдер 🇷🇺
🔝 ТБ (20.5) — кэф 1.88

💡 Тотал больше 20.5 геймов сыграл в 7 из 8 последних встреч игрока Джессика Пегула:

🔻 7 из 8 последних встреч игрока Джессика Пегула.

По цифрам ставка на ТБ (20.5) смотрится интересно в этой встрече 😎

👉 Подобные прогнозы на другие виды спорта
👉 Наш основной канал
🔥 …
```

### `locked_facts`
- `home`, `away`, `line`
- Строка `format_stat(stat_text, "🔻")` целиком (с 💡 и 🔻)
- `odds`

### Промпты

| Роль | Шаблоны |
|------|---------|
| System copywriter | `copywriter_base.md` + **`copywriter_trend.md`** + `scores24.md` + `meta.md` |
| User | `user_trend.md` |

> **Нюанс:** в коде `bet` и `trend` делят один набор copywriter-шаблонов (`_copywriter_kind` → `"trend"`). В `copywriter_trend.md` написано «используй слово Тренд», а шаблон без LLM для `bet` говорит «Ставка дня». При включённом LLM модель может переписать intro под «Тренд» — это известное расхождение промпта и шаблона.

### Валидатор (специфика)
- Ровно одна нога
- Факт `💡 … 🔻 …` должен **буквально** присутствовать в тексте (иначе «нет факта из JSON»)

## 4. Тренд (`trend`)

### Описание
**Одна нога** со статистическим трендом (источник trends / top-пул). С картинкой. По структуре похож на ставку дня, но intro/closing про **«Тренд»**.

### Откуда данные
- `GET /rapi/localized/trends/list` — первый тренд с эндпоинта (бэкенд уже отсортировал)
- Селектор: без коридора кэфа, только kickoff / слот

### Кто пишет текст
- **Код:** как у bet, но `format_stat(..., "✅")` (маркер ✅)
- **LLM:** `intro`, `closing`, `promo_text` — обязательно слово «Тренд»

### Пример вывода

```
Тренд (футбол) в рамках чемпионата России 🤑

⚽️ Футбол:

Спартак - ЦСКА
🔝 Обе забьют (Да) — кэф 1.70

💡 Обе команды забивали:

✅ в 8 из 10 последних очных встреч Спартака и ЦСКА.

Статистика намекает, что Обе забьют (Да) здесь стоит на примете 😎

👉 Другие тренды на сегодня найдешь здесь
👉 Наш основной канал
🔥 …
```

### `locked_facts`
- `home`, `away`, `line`
- `format_stat(stat_text, "✅")` целиком
- `odds`

### Промпты
Те же, что у **bet** (см. таблицу выше), `post_type="trend"`.

### Валидатор (специфика)
- LLM-валидатор: ошибка, если в intro/closing написано «Ставка дня» вместо «Тренд»
- Факт `💡 … ✅ …` должен быть в тексте дословно

## Валидатор: что проверяется всегда

Файл: [`smm/validator.py`](smm/validator.py). Два слоя:

### 1. Железные правила (`_iron_checks`) — всегда первыми

| Проверка | Смысл |
|----------|--------|
| **Факты из JSON** | Каждая строка из `locked_facts` есть в `text` или `text_html` (как подстрока) |
| **Лишние числа** | Любое число в тексте должно быть в `locked_facts`, дате или текстах ссылок |
| **Длина** | ≤ 4096 без картинки, ≤ 1024 в caption с картинкой |
| **Картинка** | Файл существует и не пустой |
| **Ссылки** | URL начинается с `http://`, `https://` или `t.me` |
| **Kickoff** | Матч ещё не начался (для top_matches — строго) |
| **Коридор / ноги** | express ≥2 ног; top_matches только football |
| **Стоп-фразы** | «гарантированно», «100%» (если нет в фактах), «без риска», … |

Если железо нашло ошибку → статус `needs_human`, LLM-валидатор **не вызывается**.

### 2. LLM-валидатор (`_llm_checks`) — если есть `OPENAI_API_KEY`

System: `validator.md` + `scores24.md` + `meta.md` (+ `validator_top_matches.md` для top_matches).

На вход: `text`, `post_type`, `locked_facts`.  
Ответ: `{"ok": true/false, "errors": [...]}`.

### Автопочинка (`auto_validate_and_fix`)
До 3 попыток:
1. Пересинхронизировать кэфы с API
2. `repair_intro` — LLM переписывает intro/closing/promo по списку ошибок (`user_repair.md`)

Если не помогло → `needs_human` + сообщение в админ-бот.

## Статусы черновика

| Статус | Значение |
|--------|----------|
| `approved` | Валидатор пропустил, ждёт слот |
| `needs_human` | Ошибка, нужна ручная правка в боте |
| `published` | Ушло в канал |
| `settled` | После матчей дописаны ✅/❌ |
| `skipped` | Не опубликован (матч уже начался) |
